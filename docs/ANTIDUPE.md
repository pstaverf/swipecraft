# Анти-дюп: векторы Bedrock и где каждый закрывается

Три уровня защиты, и путать их нельзя:

- **S — скрипт** (мы можем проверить/замедлить/убрать аномалию),
- **C — конфиг сервера** (`server.properties`, геймрулы, версия BDS),
- **M — только Mojang** (движковая бага, скрипт её не видит и не исправит),
- **A — админ-процесс** (организационная мера).

| # | Вектор | Уровень | Что делает скрипт | Что делает конфиг/процесс |
|---|---|---|---|---|
| 1 | Дюп через перегрузку контейнеров (быстрое открытие/закрытие, двойные сундуки, шалкеры) | S + M | троттлинг открытий (`containerOpsPerWindow`), отмена события, аудит | — |

## Что скрипт реально делает в коде

`src/security/antidupe.ts`:

- троттлинг открытия контейнеров с отменой события (`event.cancel`) — предотвращает дюп-циклы, а не наказывает игрока;
- учёт подборов предметов, аудит флуда;
- фиксация «смерть → респавн < 2.5 с» (классический признак дюпа через смерть);
- очистка внутренних счётчиков при выходе игрока (нет утечек памяти).

`src/security/anticheat/index.ts`:

- скан инвентаря на стопки > `maxStackAmount` (вес 25, самый тяжёлый вес);
- счётчики дропа и контейнеров.

`src/world/limits.ts`:

- лимиты хопперов/наблюдателей/поршней на чанк: превышение → блок возвращается в инвентарь, аудит;
- кап TNT в радиусе: лишние сущности удаляются, аудит.

## Честные ограничения

1. **Счётчики блоков на чанк начинаются с нуля после рестарта.** Скриптового API чтения блоков чанка нет (перебор 16×16×384 блоков на чанк — это гарантированный лаг). Поэтому лимит действует на блоки, поставленные после старта. Уже стоящие фермы ловятся капом TNT и лаг-метриками, а не поштучным учётом.
2. **Отката предметов нет** — по требованию. Скрипт возвращает только блоки, которые сам отменил.
3. **Абсолютное большинство дюпов — движковые баги.** Единственная реальная защита — актуальный BDS: обновление при выходе каждого патча (обновление делается `deploy/update-bds.sh`, мир сохраняется).
4. **Аудит — не доказательство.** Для бана нужен ручной разбор: повторяемость, время, инвентарь, видео. Аудит даёт след, а не приговор.
